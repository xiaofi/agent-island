# Agent Island Promo Video

30 秒左右的 Agent Island 推广短片。画面强调科技感，但文案只使用项目已确定的产品边界：

- 本地桌面悬浮状态层。
- 展示 Codex / Claude Code 等 agent 会话状态。
- 旁路观测，不接管 agent 执行流程。
- 不默认读取完整对话内容，不向云端上传数据。

## Commands

**Install dependencies**

```console
npm i
```

**Start preview**

```console
npm run dev
```

**Render video**

```console
npm run render
```

输出文件：

- `out/agent-island-promo.mp4`
- `out/agent-island-promo-silent.mp4`
- `out/agent-island-bed.wav`

`out/` 默认不纳入 Git。
